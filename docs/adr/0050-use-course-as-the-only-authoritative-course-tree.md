# Use `course/` as the only Authoritative Course Tree

The target repository layout will use `course/notebooks/`, `course/checkpoints/ch01` through `ch09`, and `course/tools/` as the sole course source hierarchy, with the generated Reusable Harness under `src/agent_harness/`, tests under `tests/`, and decisions under `docs/adr/`. The final production package must be generated only from chapter 9. Existing `courses/`, release copies, and the root Raw Notebook remain unchanged as historical inputs until the new course passes every Release Gate; only then may they be moved to an archive such as `archive/raw/mini_harness.ipynb`. Deferring cleanup preserves evidence and avoids destructive migration before the replacement is proven, while declaring one future authority prevents parallel course implementations from continuing to diverge.
