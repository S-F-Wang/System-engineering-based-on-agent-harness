# Use nine substantive course chapters

The course will contain nine cumulative Chapter Notebooks: (1) model messages, content blocks, ScriptedModelAdapter, and the OpenAI-compatible adapter; (2) the async AgentRuntime, Events, stop outcomes, retries, and failure settlement; (3) structured Tools, validation, ToolResult, ToolExecutor, and deterministic parallel batches; (4) cancellation, one active Agent Run, Steering Messages, and Follow-up Messages; (5) tree-structured Sessions, memory and JSONL stores, Settled Boundaries, and recovery; (6) Compaction and context retention; (7) Events, Hooks, Extensions, and explicit resource injection; (8) Skills, Prompt Templates, ResourceLoader, scope, and trust in the Coding Agent layer; and (9) the public Python API, `omega exec`, `omega chat`, TUI-ready boundaries, end-to-end verification, and release. Installation and course navigation belong in the README rather than an artificial setup chapter. This grouping favors coherent concepts and limits Checkpoint overhead without collapsing Pi-aligned responsibility boundaries.
