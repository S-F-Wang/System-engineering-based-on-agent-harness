# Use dataclasses, Protocols, and explicit JSON Schema

Version one will represent messages, Events, configurations, and results as typed dataclasses, using frozen value objects where practical. Replaceable infrastructure boundaries such as ModelAdapter, ToolExecutor, SessionStore, RunStore, and TraceSink use Python Protocols. Each Tool declares an explicit JSON Schema that is validated with `jsonschema` before execution; schema inference from function signatures is out of scope. Callers may adapt Pydantic-generated schemas, but Pydantic is neither a core dependency nor the harness's public type system. Provider dictionaries remain inside OpenAICompatibleAdapter, while Session and Trace formats use explicit versioned encoders and decoders instead of unconstrained dataclass serialization. This keeps contracts visible in the course and preserves the existing prototype's direction.
