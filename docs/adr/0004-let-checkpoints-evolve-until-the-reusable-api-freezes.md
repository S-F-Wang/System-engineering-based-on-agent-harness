# Let Checkpoints evolve until the reusable API freezes

Every Checkpoint will remain reproducible once created, but early Checkpoints will not promise API compatibility with later chapters. Chapters may deliberately replace an earlier simplification when the new boundary is taught and the migration is explained; only the completed Reusable Harness becomes a compatibility-bearing public package. This avoids freezing teaching scaffolds into the infrastructure API while preserving every historical construction stage.
