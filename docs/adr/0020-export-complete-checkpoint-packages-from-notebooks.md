# Export complete Checkpoint Packages from Chapter Notebooks

Each Chapter Notebook will contain explicitly tagged Export Cells that name their target Python modules. Exporting a chapter starts from the preceding Checkpoint Package, carries forward modules the chapter does not address, and replaces every addressed module with the ordered contents of that chapter's Export Cells for that module. Narrative, demonstration, and visualization cells are never exported. The exporter must build into a temporary location and pass compilation, import, and checkpoint tests before publishing the immutable Checkpoint Package. The final `src/agent_harness` package is generated from the last Checkpoint and is not maintained by hand. This preserves cumulative, runnable course chapters without accumulating duplicate definitions or creating a second production source of truth.
